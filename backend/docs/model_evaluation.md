## Notes

Written by hand after the runs on 12/11/2026 (yolo11n, 100 epochs, 52 phone and camera images, Roboflow version 4).

- **The test set is very small.** 7 images and 36 instances, and most classes have 1-3 instances in it.
  One missed box moves a class from 0.995 to 0, so the per-class numbers mainly show the trend.
  Compare models on the same test set only.
- **Fixed labeling error: carrot.** In `phone_WhatsApp_Image_2026-11-12_at_13-20-16 (2)` the bag of carrots
  was labeled `cucumber`, which gave carrot an mAP@50 of 0 although the model detected it correctly.
  After fixing the label carrot is at 0.995.
- **Classes with little training data perform worst:** rich_cream (1 training instance), cucumber (2),
  cottage_cheese (2), tortillas (4), eggs (5) and cooking_cream (6). They need more labeled images first.
- **yellow_cheese** has 11 training instances but most are the red "צהובה מגורדת" bag on the top shelf,
  while the test set also has blue sliced-cheese packages. It needs images of more yellow-cheese packages.
- yogurt, lettuce and onion are not labeled in any image yet, so they are not measured.

### Enhanced images (vision.preprocess.enhance) for detection

The pipeline enhances each image (denoise, lighting, sharpen) before detection. To check whether the
detector should see enhanced images, three setups were compared on the same split
(`split_dataset.py` with and without `--enhance`):

| Setup | Test mAP@50 | Test recall | Val mAP@50 | Val recall |
|---|---|---|---|---|
| Train raw, detect raw | **0.677** | 0.590 | **0.739** | 0.696 |
| Train raw, detect enhanced | 0.673 | 0.680 | 0.706 | 0.660 |
| Train enhanced, detect enhanced | 0.489 | 0.482 | 0.685 | 0.588 |

- Training on enhanced images did **not** help: it was the worst setup on both sets.
- A model trained on raw images works about as well on enhanced images as on raw ones.
- Decision for now: train on raw images (`storage/models/detector.pt`), and run detection on the
  image before `enhance`. The enhanced image is still useful for the OCR step.
- These are mostly phone photos converted to look like ESP32-CAM images. Enhancement was designed for
  the darker, bluish camera frames, so compare again once the dataset has more camera images.
