## Notes

Written by hand after the run on 12/11/2026 (yolo11n, 100 epochs, 52 phone and camera images).

- **The test set is very small.** 8 images and 36 instances, and most classes have 1-3 instances in it.
  One missed box moves a class from 0.995 to 0, so the per-class numbers mainly show the trend.
  Compare models on the same test set only.
- **carrot is a labeling error, not a model error.** In the test image
  `phone_WhatsApp_Image_2026-11-12_at_13-20-16_-2-` the bag of carrots is labeled `cucumber`.
  The model detects it as `carrot` (0.89), which is counted as both a missed carrot and a false cucumber.
  This also lowers cucumber. Fix the label in Roboflow, and check the other large `cucumber` boxes:
  `phone_WhatsApp_Image_2026-11-12_at_13-20-11` and `f37ff0004582f8c9_cam1` (training set).
- **Classes with little training data perform worst:** rich_cream (1 training instance), cucumber (2),
  chocolate_pudding (4) and tortillas (5). They need more labeled images first.
- **yellow_cheese** has 11 training instances but recall 0 on the test set. Its test instances are blue
  sliced-cheese packages, while most training instances are the red "צהובה מגורדת" bag on the top shelf.
  It needs images of more yellow-cheese packages.
- **bell_pepper**: the only test instance is a small pepper partly hidden in a bag.
- yogurt, lettuce and onion are not labeled in any image yet, so they are not measured.
